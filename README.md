# Smartphone AI Analyst

## Overview

Smartphone AI Analyst is an AI-powered recommendation system that helps users choose smartphones based on their budget, preferences, and usage scenarios.

The project combines structured product data, prompt engineering, and GPT models to generate personalized recommendations and explain the reasoning behind each choice.

## Project Goal

Develop an AI consultant capable of:

* Understanding user requirements
* Selecting suitable smartphone models
* Comparing alternatives
* Generating personalized recommendations
* Evaluating recommendation quality

## Features

* Budget-based smartphone selection
* User requirement analysis
* AI-generated recommendations
* Product comparison
* Recommendation quality evaluation
* Experimentation with different model settings

## Technologies

* Python
* OpenAI API
* GPT-4o
* Pandas
* NumPy
* FAISS
* Prompt Engineering

## Project Structure

* smartphone_ai_analyst.ipynb — main project notebook

## Results

The project was developed as a final AI Specialist diploma project and demonstrates the practical application of GPT models for recommendation systems and product analytics.
